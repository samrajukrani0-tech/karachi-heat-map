Reproducing this

Everything is open. The repository is samrajukrani0-tech/karachi-heat-map; every raw download is checksummed, and the pipeline rebuilds the whole model from the cache.

Priority is a ranking within Landhi Town, not a measurement of risk on any absolute scale, and not a prediction of deaths. This is not an official warning system — for warnings follow the Pakistan Meteorological Department and PDMA Sindh.

Built with Claude Code as a coding assistant. Research question, modelling decisions, weights and fieldwork by Samraj Lal Ukrani.
